# Технический радар: расширенная версия (Tech Radar)

## Техники (Techniques)

| Техника / Паттерн         | Статус | Пояснение                                                                                           |
| ------------------------- | ------ | --------------------------------------------------------------------------------------------------- |
| Data Mesh                 | Adopt  | Базовый подход к распределённому управлению данными, при котором ответственность лежит на доменах. |
| Event-Driven Architecture | Adopt  | Целевая архитектура строится на асинхронном обмене событиями между доменами.                         |
| Self-service BI           | Adopt  | Через портал сотрудники бизнеса могут создавать отчёты без постоянного участия ИТ-команды.          |
| Data Product              | Adopt  | Каждый набор данных оформляется как продукт: с ответственным владельцем, SLA и документацией.       |
| Federated Governance      | Trial  | Общие правила управления данными сочетаются с самостоятельностью доменов; внедрение начнётся на втором этапе. |
| Data Contract             | Trial  | Соглашения между поставщиками и пользователями данных определяют схемы и требования к качеству.      |
| Data Observability        | Assess | После пилотного этапа планируется внедрить контроль качества данных и их lineage.                    |

## Платформы (Platforms)

| Платформа                                    | Статус | Пояснение                                                                                             |
| -------------------------------------------- | ------ | ----------------------------------------------------------------------------------------------------- |
| Облачная инфраструктура (Yandex Cloud / AWS) | Adopt  | Среда для размещения компонентов системы, обеспечивающая масштабирование и устойчивость к сбоям.      |
| Apache Kafka (Confluent)                     | Adopt  | Платформа обмена событиями доменов, дополненная Schema Registry и KSQL.                               |
| Data Lakehouse (S3 + Iceberg + Nessie)       | Adopt  | Аналитическое хранилище, поддерживающее транзакции ACID и управление версиями.                        |
| Trino (Presto)                               | Adopt  | Распределённый движок SQL-запросов к Data Lakehouse и прочим источникам данных.                       |
| DataHub                                      | Adopt  | Каталог, помогающий находить данные и работать с метаданными дата-продуктов.                          |
| Apache Airflow                               | Adopt  | Инструмент для управления ETL/ELT-конвейерами и формирования витрин данных.                           |
| Kubernetes                                   | Adopt  | Средство управления контейнерами микросервисов и сервисов платформы.                                 |
| Power BI / Superset                          | Trial  | Power BI сохраняется ради совместимости, а Superset рассматривается как открытая альтернатива.       |

## Инструменты (Tools)

| Инструмент           | Статус | Пояснение                                                                             |
| -------------------- | ------ | ------------------------------------------------------------------------------------- |
| Kafka Connect        | Adopt  | Подключение источников и систем-получателей, включая базы данных, S3 и устаревшие системы. |
| Debezium             | Adopt  | Отслеживание изменений (CDC) в операционных базах с последующей отправкой событий в Kafka. |
| dbt                  | Trial  | Подготовка и преобразование данных в Data Lakehouse с помощью SQL-моделей.              |
| Terraform            | Adopt  | Описание и развёртывание инфраструктуры средствами подхода IaC.                        |
| Keycloak             | Adopt  | Единая система управления идентификацией и доступом для аутентификации и авторизации.  |
| Prometheus + Grafana | Adopt  | Сбор метрик и наблюдение за состоянием приложений и инфраструктуры.                    |
| Apache Flink         | Assess | На втором этапе рассмотрят применение потоковой обработки для аналитики почти в реальном времени. |
