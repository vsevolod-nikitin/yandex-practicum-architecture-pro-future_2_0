# Агрегаты предметных областей

## Customer Context

### Customer

| Свойство | Описание |
|---|---|
| Состав | Идентификатор клиента, ФИО, дата рождения, контактные сведения и разрешения на обработку персональных данных |
| Правила | Адрес электронной почты и номер телефона должны быть уникальными; согласия фиксируются только после явного подтверждения |
| Идентификатор | `customerId` (UUID) |

## Medical Context

### Patient

| Свойство | Описание |
|---|---|
| Состав | Идентификатор пациента (тот же, что `customerId`), номер медицинской карты, назначенный врач и полис ОМС/ДМС |
| Правила | Создать пациента можно лишь после его регистрации в Customer Context |
| Идентификатор | `patientId` (UUID) |

### Appointment

| Свойство | Описание |
|---|---|
| Состав | Дата и время визита, пациент, врач и состояние приёма: запланирован, завершён или отменён |
| Правила | Расписание врача не должно содержать пересекающихся приёмов |
| Идентификатор | `appointmentId` (UUID) |

### Diagnosis

| Свойство | Описание |
|---|---|
| Состав | Код по МКБ-10, формулировка диагноза, дата установления и приём, к которому он относится |
| Правила | Зафиксировать диагноз разрешено только по итогам завершённого приёма |
| Идентификатор | `diagnosisId` (UUID) |

### ImagingStudy

| Свойство | Описание |
|---|---|
| Состав | Вид исследования (например, рентген или МРТ), дата выполнения, текущее состояние и ссылки на результаты |
| Правила | Запрос на исследование принимается только для зарегистрированного пациента |
| Идентификатор | `studyId` (UUID) |

## AI Diagnostics Context

### AIAnalysis

| Свойство | Описание |
|---|---|
| Состав | Идентификатор исследования, используемая модель ИИ, исходные данные (изображения или сигналы), вывод и состояние анализа |
| Правила | Итог анализа обязательно включает показатели уверенности |
| Идентификатор | `analysisId` (UUID) |

## Fintech Context

### Account

| Свойство | Описание |
|---|---|
| Состав | Номер счёта, его владелец (`customerId`), остаток средств, валюта и состояние счёта |
| Правила | Для расчётного счёта отрицательный остаток недопустим; овердрафт возможен только по кредитному счёту |
| Идентификатор | `accountId` (UUID) |

### Loan

| Свойство | Описание |
|---|---|
| Состав | Размер займа, период кредитования, ставка, план выплат и состояние заявки |
| Правила | Запрашиваемая сумма не может превышать установленный для клиента лимит |
| Идентификатор | `loanId` (UUID) |

## Billing Context

### Invoice

| Свойство | Описание |
|---|---|
| Состав | Номер документа, итоговая сумма, перечень услуг (приёмы и исследования) и состояние оплаты |
| Правила | Итог в счёте должен соответствовать стоимости фактически оказанных услуг |
| Идентификатор | `invoiceId` (UUID) |

## Inventory Context

### InventoryItem

| Свойство | Описание |
|---|---|
| Состав | Название позиции, доступное количество, единица учёта и порог минимального остатка |
| Правила | Остаток товара или материала не может быть меньше нуля |
| Идентификатор | `itemId` (UUID) |

## Staff Context

### StaffMember

| Свойство | Описание |
|---|---|
| Состав | ФИО работника, его должность, рабочее расписание и подразделение |
| Правила | За сотрудником закрепляется не более одной основной должности |
| Идентификатор | `staffId` (UUID) |
